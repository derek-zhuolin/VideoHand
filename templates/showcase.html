From a thought to a film

换个模型，也走同一条创作路径。

模型负责理解和写计划，工具负责校验与渲染。
画面规则、素材和工程都留在你手里。

01 / Understand

读懂完整意思

提供录制视频和带时间的转录。Agent 先找核心关系、限定条件与表达重点，再决定画面承担什么。

02 / Direct

安排人物和物件

写一份通用 JSON 计划，选择主镜头、辅助解释、图解与圆形小窗，让物件沿语义连续运动。

03 / Refine

预览，修改，带走

检查画面和原声，局部修改当前 HTML 工程，导出 MP4。图标、字体和时间轴随工程保存。

Provider-independent

不绑定模型厂商。

CodexClaudeGeminiDeepSeek

这些是可接入的模型／Agent 选择，不是逐一实测背书。需要宿主提供读写文件和命令执行；仅聊天的模型可先生成计划，再交给本地 CLI。

查看兼容边界与通用提示词 ↗

从 GitHub 源码开始，无需模型 API key：

node bin/videohand.mjs doctor node bin/videohand.mjs compose \ --plan examples/director/framed-presenter.json \ --out ../my-film

Node.js ≥ 22 · HyperFrames · ffmpeg / ffprobe
ASR、自动找脸、抠像和实时直播不包含在本版本。

这套风格从哪里来？
Oreo 提供原始图标与手绘视觉基准；VideoHand 加入连续物件、录制口播编排与可编辑工程。瀑布流用于浏览能力，成片仍沿语义展开。查看来源与许可。
