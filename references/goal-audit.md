# 升级能力与验收边界

这份索引用于区分可复用工程能力、公开示例和私人样片。它不声明所有原始构想已完成。

| 范围 | 当前交付 | 边界 |
| --- | --- | --- |
| 录制口播离线编排 | prepare / compose / inspect / revise | 一个连续视频与原声，不自动跳切或 ASR |
| 语义分镜 | 原话、核心意思、关系、视觉任务、理由及连续时间范围 | 由 Agent 阅读上下文编写；CLI 负责校验 |
| 连续物件 | 稳定对象 ID、归属、累积、交接、负载、聚焦、强调 | 有限组件库，不是任意动画生成器 |
| 人像与图解 | a / a-support / b-pip / b 四种构图 | 不自动找脸、抠像或智能选择空位 |
| 本次视觉升级 | framed 配置，等比留白、白内画布、轻阴影、圆形 PiP、字幕上移 | 老计划使用 classic；每片检查裁切和遮挡 |
| 私人样片 | 本地一份 50.5 秒竖屏录制口播迭代及同步检查 | 素材不公开；不代表真实人像横竖所有情境验收 |
| 公开案例 | 容量交接、团队协作、同内容暖纸对照、无源媒体构图示例 | 均标注中性研究/示意，不冒充真人成片 |
| 可编辑工程 | 当前 HTML 为依据，局部 revise 备份并校验 | 不保证任意 Studio 操作自动往返 |
| 模型兼容 | 同一 JSON / CLI，无模型 provider API 依赖 | 不是所有模型的语义质量实测 |
| 展示页 | 瀑布流作品、可播放示例、152 个原始图标搜索、来源许可 | 页面视觉示意与实际影片明确区分 |
| 发布脱敏 | 原片、原声、转录、私人路径与联系方式不进入本次公开内容 | 不包含对已有 Git 历史的重写 |

具体检查结果见 [validation.md](validation.md)。未包含自动抠像、实时会话、任意素材矢量化、自动删口误或 SaaS 托管服务；真实人像横屏与更多题材仍需独立样片验证。
