# Icon 优先口播构图

此创作预设适用于已录制口播：用户希望保留本人表达，同时让简洁的手绘 Icon 承担解释。它补充 [导演工程](director.md) 的语义编排，不新增 runtime、schema 字段或 CLI preset。用户已有的明确布局、画幅和本次反馈优先；无露脸视频继续使用 [无露脸动作编排](continuous-noface.md)。

[20 秒公开示例与构建说明](../examples/icon-first/README.md) 演示复用、受阻和沿路径补画，使用通用文案与手绘人物占位。它提供可编辑 HTML，不包含私人影像或原声。

## 让 Icon 成为画面的主角

同一时刻简单，随时间丰富。一镜只解释一个意思，保留一个主物件、最多两个辅助图形；这指承担叙事的图形对象，不能拆成多层小装饰绕过限制。标题、字幕和人物也占据注意力，不能因不计入图形数量就无限增加。

从 `assets/doodle/icons/` 选用原版 Oreo SVG，保留路径、笔触和比例，通过外层尺寸缩放；不要重新 rough 化、混用其他图标库或用手绘容器包住很小的图标。来源、许可及原版视觉参考见 [Doodle 设计基准](doodle-design.md)。

主图应大到在手机预览中能一眼辨认，辅助图形明显次于主图。大纸张、底色椭圆、散落曲线与装饰小符号默认移除；只有纸张本身就是解释对象、底色有分组意义、连线表达真实关系时才使用。内容丰富来自对象的动作和状态变化，不能来自填满留白。

## 人物与画面分工

此预设以右下圆形小窗为常态，保留脸部表情，让主要空间用于 Icon 解释。小窗要避开主图轨迹、标签和字幕；先查看真实素材，再确定位置、直径和裁切，不自动推断人脸中心。

关键判断、经历或情绪需要本人强调时，可以让人物短暂居中。该时段配合一个语义相关的 Icon 动作，例如说到“使用门槛”时让锁扣合，构成 `a-support`；动作不遮挡脸和手势。不要把同一个巨大人像框停在大片空白中，也不要用一组无关贴纸填空。

回到小窗时，让同一 Icon 接着行动，观众能追踪它的状态。切换依据是表达用途，不规定所有视频的出镜比例或固定秒数；用户明确要求完整真人镜头时尊重其选择。当前圆形小窗与留白画布的配置边界见 [导演工程](director.md)，定制连续变形等效果须在可编辑 HTML 中实现，不能宣称 schema 已自动支持。

## 标题、主图、字幕三个区域

先画三个不重叠的安全区域，再放人物小窗：上方短标题，中部 Icon 关系，下方稳定字幕。围绕共同轴线安排，按实际画幅调整主图高度；不靠无意义的空白将相关内容拆散。横屏和竖屏分别构图，不把一次竖屏样片的像素位置套进所有项目。

- 标题只概括此刻的意思，短而醒目；不另加副标题、品牌栏、页脚或重复说明。
- 主图区保持一个焦点，相关标签靠近对应物件，不将说明藏在边角小字里。
- 字幕使用随包 Xiaolai，按手机尺寸检查字号与换行。每句最多一个来自原话的关键词，以杏仁色 `#ECB775` 不规则手绘笔触作衬底；其余文字保持墨色。不把整句放进矩形色块，不逐字弹跳。关键词可以随字幕出现画出，之后稳定停留。

白底、墨线与克制强调色保持统一。沿用用户选定的浅色外底、留白和阴影时，只把它们作为画布层次；不要再在主图后叠一套容器和大色块。

## 用动作讲关系

先写一句可观察的事件：“谁做了什么，导致谁改变”。再安排起步、移动、减速落位与下一动作，使用有目的的 easing；前一动作落位时，下一动作可以提前少量启动。保留对象身份，避免每个字幕句子都清空画面、重新出场。

| 要解释的关系 | 可用的简洁动作 | 容易误做成的装饰 |
|---|---|---|
| 可复用 / 兼容 | 同一个拼图接入不同工具，连接后带动工具回应 | 展示一墙工具图标 |
| 阻碍 / 门槛 | 主物件前进，锁扣合使其受阻，保留受阻状态 | 一个锁在旁边无限晃动 |
| 补充 / 二创 | 铅笔补出图片的一部分，新增内容改变画面状态 | 纸张、铅笔和曲线各自漂浮 |

上述是关系示例，不能仅凭口播出现某个词就机械配图。相机可保持稳定，阅读停留可以存在；连续性来自动作的承接与因果，不来自所有像素持续变化。增加节奏优先调整动作长度、错峰和语义锚点；没有用户授权，不为视觉节奏擅自加速原声或重写原话。

## 小样复核

按 [验收标准](quality.md) 渲染并正常速度观看后，另外核对：

1. 暂停任意主要画面，能否立刻说出主角和它正在表达的关系？辨识不到主角时先删层、放大 Icon，不继续加元素。
2. 居中人物时是否确实有表达用途，相关 Icon 动作是否清楚，人物返回小窗后对象能否接续？
3. 手机尺寸下能否看清原版笔触和关键词衬底？标题、字幕、人物与运动轨迹是否互不遮挡？
4. 连续观看时，是否在同一个对象上看见“发生了什么”和“接下来因此怎样”？若只有摆动与淡入淡出，不算完成语义动作。

这份文档是创作与复核约定；它不代表 runtime 会自动选择 Icon、找到人脸、避让布局或通过审美验收。
