# 配音与字幕：提供方无关的接口

接受用户提供的音频，或用户已经授权并配置的 TTS。火山引擎、慕斯等提供方都可通过相同音频接口接入；本包不内置任何人的 voice ID、克隆素材、API key 或机器专用路径，也不声称已集成所有提供方 API。

1. 在当前项目写 narration.txt，使用已批准的文案。先检查用户已有配置与选择；只读其明确授权的配置，不能默认扫 `~/.claude/.env`。
2. API 凭证仅由用户指定的环境变量或配置提供给其适配器。不要写入 JSON、日志、工程或 Skill；成本/外发动作按本次授权处理。
3. 生成 voice.wav/mp3，用 ffprobe 读取真实时长，得到逐句或逐词时间。可用提供方时间戳、ASR 或人工对齐；不得用等分时长伪造对齐。
4. 音频和已对齐字幕进入工程配置。时间单位秒：

   ```json
   {
     "audio": {"path":"./voice.wav", "start":0.4, "duration":18.41},
     "captions": [{"start":0.4,"end":2.2,"text":"第一条实际配音"}]
   }
   ```

   audio.path 相对配置文件所在目录；字幕是相对全片的绝对时间，已经包含 0.4 秒偏移。不得二次加偏移。composition.duration ≥ start + 实测音频时长，末尾留合理余量。
5. 构建器核对音频文件时长（容差 .12 秒），拒绝越界/重叠字幕。字幕字形也会检查。
6. 成片试听：无漏字、截断、爆音、重叠或明显不同步。报告 TTS 提供方，不暴露秘密。没有可用音源可先做明确标注的静音预览，不能假装已完成有声片。

换词或重生成 TTS 后重新对齐字幕、分镜与时长。保留横竖两版共同的音频时间轴，布局可以不同。
