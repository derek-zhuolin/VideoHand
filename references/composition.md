# 构图、分镜与持续场景

从 VideoHand v2 保留：比例布局、安全区、字号层级、文字装框、标注锚定、离场归零。
从 anything2explainer 学习：先内容来源，再解说与音频，再分镜；全片同一例子，每段一个主角，按真实时间对齐；成片关键帧与边界复核。
不迁移其黑底紫光、Remotion、固定镜头数量、“一句一镜”、每章固定运镜次数或多 Agent 配额。别人不必安装该 Skill。

### 3.0 的减法规则

每个画面先确定一个主焦点。字幕用关键词衬底提示听觉重点，画面本身不再同时叠加标题、说明、页脚和重复 CTA。框线只在“关系需要被装起来”时出现，例如一组输入输出、对照面板或 Reference 录屏；单个图标、人物画中画和过场留白不自动套框。一个 20–60 秒片段通常保留 2–4 个框线段落，其余时间让纸面呼吸。

## 先描述关系，再选择图形

分镜每行至少记录：时间范围 / 解说意思 / 主角 / 主角当前状态→下一状态 / 画面关系 / 相机 / 字幕与来源。
过程用连接与移交；对照用左右→上下；层次用包含；聚合用多个对象合成；因果用影响传播。只有语境真正变化才更换舞台，换句不自动换场。

## 两种画幅

- 16:9 默认 1920×1080；9:16 默认 1080×1920。两者按用户要求生成。
- 四边至少留短边 7.5%；底部预留约画面高度 16% 作字幕区。字幕与 HUD 不参与运镜。
- 横屏的左右关系在竖屏转为上下，连线与箭头一起改方向；不得只缩放或裁切横屏。
- 先放一个足够大的主角，再放配角；中心示意图不是整页网页截图。正文与标注在手机宽度下仍须清晰。
- 主标题 ≤2 行；字幕优先每条中文 16 字以内 / 英文 48 字符以内，按语义拆分；需要两行时预留高度。脚手架允许的最大长度只是输入边界，不代表已经通过排版验证。
- 测量最终字体加载后的文本边界；超出先缩短/换行/重排，最后才缩字号。不能用 overflow:hidden 掩盖。

## 时间轴

同一 paused GSAP timeline 驱动位移、draw 和 boil。显式 fromTo；进度可回跳，任意 t 的画面应一致。标签随被标注对象移动，字幕保持稳定。避免靠 callback 创建/删除 DOM；所有对象提前存在，用属性控制状态。

默认入场约 .35–.55 秒、重点停留至少可读完；具体以真实配音为准。动作应该解释结构变化，不能只用“每句弹一下”制造忙碌感。最后一秒留足结论，片尾不能残留已淡出的字幕。

脚手架支持 1–4 节点起点，但复杂内容必须创作新的状态与布局，不能把四节点上限变成内容上限。
