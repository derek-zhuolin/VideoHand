# 选卡查表 · 63 张

一句话一张卡。**先判断这句话是什么形状，再查这张表**——不是先看图好不好看。

用法：在这张表里按语义定位卡名 → 打开 `assets/hw-cards.js` 搜这个卡名 → 抄它的 `build` 函数，改 `cfg` 里的文案。

- 卡的代码是**唯一真源**，这张表只是入口。
- 每张卡在 9:16 / 16:9 / 1:1 三种画幅下都成立，轴向自动翻转，卡里不写像素。
- 标 `wired` 的来自 wired-elements 配方移植（MIT）；标 `MotionSet` 的来自 MotionSet 提炼。

## 选卡纪律（写完 frames 自己过一遍）

1. **两端锁死**：首格 A 族、末格 I 族。
2. **相邻不重卡**，全片同卡 ≤1 次（≥6 格时 ≤2 次且不相邻）。
3. **相邻不重族**，全片族种类 ≥ ⌈格数/2⌉——卡名不同、版面结构同一个模子也算重。
4. **高能 ≤2 处且不相邻**：`one-word-explode` / `cross-out-correct` / `title-scribble-reveal` / `torn-paper-reveal` / `explode-parts`。
5. **低能呼吸帧 ≥1 处**：`quote-bracket-hold` / `smudge-focus` 都算，位置别固定在落版前一格。
6. **每条缝写进 STORYBOARD（硬切写 `hard-cut`）**，相邻不许同种（硬切除外），非硬切种类 ≥ ⌈非硬切数/2⌉（见 `transitions.md`）。
7. **跨片查重**：scene-lint 记账，与上一支重合 >40% 会被点名——附加族和冷门卡就是为这一条准备的。

`node scripts/scene-lint.mjs <片目录>` 会替你查 1–7 条。
